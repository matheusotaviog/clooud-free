# Clooud Free

Interface web do projeto Clooud Free. Uma landing page focada na integração de uma API simples para exibição de um catálogo de jogos grátis.

Este projeto foi desenvolvido como parte de uma das atividades práticas do curso **Dev Full Stack** da [+praTI](https://maisprati.com.br/). 

O objetivo principal desta etapa foi construir a aplicação e realizar o consumo de uma API utilizando exclusivamente tecnologias nativas da web: **HTML, CSS e JavaScript puro (Vanilla)**, sem a necessidade de frameworks ou bibliotecas externas. Dessa forma, exercitando os fundamentos estruturais, de estilização e de lógica de programação no front-end.

## 🛠️ API Utilizada

Os dados do catálogo de jogos em destaque são fornecidos pela API pública do **FreeToGame**. 

Você pode conferir a documentação completa no link abaixo:
- [FreeToGame API Documentation](https://www.freetogame.com/api-doc)
